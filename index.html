About

Who's behind the capture

I'm a systems software engineer with two years across Intel and Viasat, and an M.Tech in Computer Science from NIT Delhi. My work sits close to the machine: C++ and Python on Linux, sockets and protocol stacks, and the test infrastructure that keeps them honest.

At Intel I automated the build, deploy and run validation flow for next-generation Xeon server platforms, then built a telemetry pipeline on Kafka with machine learning anomaly detection to catch abnormal node behaviour before a human noticed it. At Viasat I owned Python automation for 4G/LTE RAN validation and moved protocol regression detection out of the release stage and into the development cycle.

Outside of work I build the primitives from scratch — an epoll-driven TCP server, a packet sniffer on raw sockets — because reading about an event loop and writing one are different kinds of understanding. I'm looking for systems, backend and platform engineering roles.
