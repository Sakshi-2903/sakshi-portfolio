About

Who's behind the capture

I'm a software engineer with over two years across platform validation, wireless and RAN software testing, and infrastructure automation — semiconductor at Intel, satellite communication at Viasat. I have an M.Tech in Computer Science from NIT Delhi and I work mostly in C/C++, Python and Go on Linux.

At Intel I automated the full build, deploy and run validation flow for next-generation Xeon server platforms, then built a 4-node monitoring platform on Kafka with ML anomaly detection and a log triage assistant that reads system logs and returns a probable root cause. At Viasat I owned Python automation for 4G/LTE RAN validation and, before that, configured GTP tunnels for TCP acceleration over satellite backhaul.

Outside work I build the primitives from scratch — an epoll-driven TCP server, a packet analyzer on raw sockets — because reading about an event loop and writing one are different kinds of understanding. I'm looking for systems, platform and infrastructure engineering roles.
